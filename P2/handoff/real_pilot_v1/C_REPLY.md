# C 回复模板

请复制到协调 Issue 的评论中，或提交填写后的文件。

## 1. 实验范围

- 本批是否先作为普通真实生成错误迁移诊断：待填
- 是否已有经核验的 seen/unseen pair 划分：有 / 暂无
- 如有：动作词表、pair 清单、版本，以及 A/B 训练与预训练暴露依据：待填
- 如无：确认本批不作 unseen pair 结论：待填

## 2. 动作标记

- 原文本动作的归类规则：待填
- 对“提起—移动—放下”等多阶段条件如何标记主动作和交互阶段：待填
- 候选条件映射表或版本（暂未完成可写未知，先采用 unknown 并注明范围）：待填

## 3. 独立复核与时间

- 能否参与争议样本独立复核：能 / 暂不能
- 预计可复核时间及完成时间：待填
- 审核时隐藏 Critic/规则分数，先独立记录判断再对照首审：确认 / 说明
- 若暂不能参与：确认报告保留单人审核限制：待填

普通迁移诊断可在组合资料未知时推进；不能将未知暴露写成未见。复核实际完成前不能宣称独立复核已完成。
