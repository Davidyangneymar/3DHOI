# 真实生成错误试标：A/C 核对提案

版本：2026-10-11，**proposal / 尚未冻结**。当前为主线第 2/6 步。

## 目标及候选

10 个条件 × 种子 `2026100501`、`2026100502`，最多 20 个槽位。候选见 [candidate_conditions.csv](candidate_conditions.csv)；它只列源身份和人工整理的动作摘要，正式英文条件由 A 从合法取得的原始 annotation 核对。

候选按固定 10 个刚体类别，各取序列名排序的第一条本地 test、有原文、至少 120 帧、不属于 B 有效训练/验证暴露的源。选择过程中没有计算模型、规则或接触分数；它不是随机代表性样本，也不能据本地 split 认定 A 未见。

每条提议使用 processed source 0–119；A 必须核对其实际 processed 数据与匹配特征。完整源可能长于 120 帧，不能假定该窗口覆盖文本描述的全部阶段；如需调整，在冻结前记录。

## A 需要回复

请填写 [A_REPLY.md](A_REPLY.md)：逐条确认源窗口可用性、视觉/几何/文本条件来源、训练暴露；确认权重、代码版本、采样设置和两个种子，并给出交付时间。完整训练或预训练来源无法核实可写未知；实际采样输入及窗口不能留空。

建议沿用已交作者权重、无 guidance、120 帧、30 FPS、与网格一致的 SMPL-X 重建关节。示例入口 seed=1 必须在批量时显式参数化，记录实际使用的随机状态设置和新版本身份。

人体/物体须处于同一空间，以米为单位、右手 Z-up，原始局部网格及列向量 local-to-world 变换须有实际映射。标准几何交付含 joints(T,24,3)、obj_trans(T,3)、obj_rot_mat(T,3,3)、obj_scale(T)，手为关节 22/23；保留原始生成网格和重建关节来源，不能用平滑修复代替原始输出。

已记录用户肯定 A 保留全部成功/失败且不经 Critic 筛选；本次重点补实际来源和批量设置。每个失败槽位提供原因，不自动补样，不按模型分数替换。

## C 需要回复

请填写 [C_REPLY.md](C_REPLY.md)：确认本批是普通迁移诊断还是已核验的未见组合评估，确认动作分类方式及独立复核安排。未核验 A/B 训练与预训练暴露时只报告普通迁移，不作 unseen 结论。

## 顺序与退出条件

1. A/C 回复后，B 将窗口、条件原文和来源等填入正式计划，绑定冻结 checkpoint、旧特征及阈值，保存计划哈希。
2. A 收到锁定计划再正式采样，交付所有预定槽位；传递输出使用双方已有的数据交付渠道，并在 Issue 留清单/标识。
3. B 核验、制备无分数盲审页，用户首审、C 独立复核。先归档标签再计算分数。
4. 同一确定标签上比较冻结 Critic 和规则。本批不用于校准、改阈值或重训；证据不足如实报告。

本提案不代表已生成 20 条结果或已完成审核。已播放的训练源格式例不属于本候选清单。
